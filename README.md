# Katas

TypeScript solutions to the exercises found in [this](https://gist.github.com/chrisvasqm/a6fca6521b61ddfb39da48ccbe156fe8) Gist.
Port of the Java solutions in [java-exercises](https://github.com/chrisvasqm/java-exercises).

## Run

```sh
pnpm install
pnpm start        # runs src/main.ts with tsx
pnpm typecheck    # tsc --noEmit
```

## Layout

| Exercise | Folder |
|---|---|
| 1 Stopwatch, 2 StackOverflowPost, 3 Stack | `src/basics/` |
| 4 Inheritance (Pokemon) | `src/inheritance/` |
| 5 Polymorphism project 1 (exporters) | `src/polymorphism/project-1/` |
| 5 Polymorphism project 2 (RPG) | `src/polymorphism/project-2/` |
